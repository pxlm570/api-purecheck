# API PureCheck 用户指南

## 一句话说明

API PureCheck 是一个本地运行的 API 纯度检测工具。它用少量请求检查中转站 API 是否像它声称的模型，并生成一份普通用户也能看懂的概率报告。

## Windows 快速开始

1. 解压发布包。
2. 双击：

```text
scripts/start_windows.bat
```

3. 浏览器打开：

```text
http://127.0.0.1:8765
```

4. 填入：

- API 地址；
- API Key；
- API 类型；
- 声称模型；
- 检测强度。

5. 先点“只预估请求数”，确认成本后再点“开始检测”。

## 检测强度

- 快速：预计 3 次请求，最低成本，适合先试通。
- 标准：预计 8 次请求，默认推荐，覆盖核心判断和关键风险项。
- 深度：预计 18 次请求，更充分，但仍控制成本。

## 报告怎么看

- 纯度结论：API 表现是否接近你填写的声称模型。
- 置信度：当前证据是否足够稳定。
- 最可能匹配：工具给出的概率参考。
- 其他模型：保留给未知模型、候选集外模型或证据不足的概率空间。
- 风险检查：检查模型身份、token 注入、上下文截断、错误泄漏、响应改写和 stream 完整性等异常。

## 隐私

API Key 只发给本机 localhost 服务，由本机向你填写的 API 地址发起请求。报告会自动脱敏。

## 重要边界

API PureCheck 输出的是概率参考，不是密码学证明，也不是投诉或法律审计报告。它适合帮你快速发现可疑链路、错误模型名、兼容性问题和明显异常。
